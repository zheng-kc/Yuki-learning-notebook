## 3. 纯 LLM 子集去重效果(dry-run,不动库)

对 extract_cache 里 220 条 LLM 知识点独立跑 dedup(0.85阈值):

- 220 → 归并 3 条 → 217,去重率 **1.36%**
- **3 组归并全部是跨材料有效合并(100%)**:
  - 嵌顿性疝手法复位适应证(普外.md ← 普外科 .md)
  - 乳腺淋巴输出的4个途径(普外.md ← 外科学（普外）.md)
  - 类癌综合征(普外.md ← 普外科 .md)
- 结论:**LLM 提取几乎零碎片噪声;一旦归并必为真正的跨材料同考点。**

### ⚠️ 关键发现:0.85 阈值对 LLM 长文本知识点太严格
- 去重率仅 1.36%,远低于规则切分的 70%。
- 原因:LLM 知识点平均 228 字,SequenceMatcher 要求整串 ≥85% 相似。同一考点在不同材料表述差异大(如"手术适应证"vs"手术指征")时认不出。
- **影响**:后续 weight.py 高频判定若只靠 dedup 的 dup_count,LLM 数据会低估重复。**建议为 LLM 数据引入语义相似度**或**降低阈值**,(README 已预留"语义接口")。

## 4. 全库 dedup dry-run(2900 条)

命令:`python pipeline\dedup.py --db data\mk.db --threshold 0.85 --dry-run`

- 2900 → 归并 150 簇/191 条 → 2709,去重率 **6.59%**
- **150/150 簇主条目均来自 LLM 提取**(LLM 长条目 228 字远长于规则切分碎片 → dedup"保留更长条目"策略下自然成为主条目,吸收规则碎片)。
- Top dup 碎片("正确答案：C/D/E" dup=6/6/6)经查 **created_at=2026-09-09,是规则切分残留,非 LLM 产物**。
- 结论:LLM 提取的高质量条目**反向收编**了库内规则切分碎片,去重正向净化库。
