# 语义去重层效果测试(2026-09-13)

> 在 extractor 220 条 LLM 知识点上,测试「加一层语义判重(LLM)vs 纯算法去重」的效果。
> 数据文件均保留:extract_cache.json / llm_dedup_candidates.json / 临时库不动。

## 背景与规模
- 220 条知识点,两两 24090 对,其中 98.9% 相似度<0.40(无关)
- SequenceMatcher 合并 3 对(220→217)
- 算法未合并但 sim 0.40~0.85 的候选对:**71 对**

## 语义层实测(LLM chat 判重,deepseek-chat temperature=0)
- 71 对候选 → LLM 判 **25 对应合并**,46 对不合并
- 人工核验 25 对:

### ✅ 真合并(约 2/3,补上算法漏掉的真实考点)
- 乳腺淋巴输出途径:5 对(重点整理/普外/普外名解/外科学普外/普外科 跨材料同一考点)
- 麦氏点/阑尾体表投影:3 对
- 肛裂/肛瘘/直肠肛管周围脓肿/短肠综合征/难复疝易复疝:各跨材料定义
- 肛裂三联症

### ❌ 误合并(约 1/3,低相似度段乱判)
- [0.50] 胆道系统应用解剖 ↔ 甲状腺解剖生理概要:完全无关器官,错
- [0.53] 甲状腺解剖/生理功能 ↔ 泛泛"解剖生理概要":偏错
- [0.51][0.41] 斜疝直疝鉴别表 ↔ 疝/腹外疝定义:主题同属疝但点不同,边界模糊
- [0.85] 直肠肛管周围脓肿 ↔ 外科学肛管定义:存疑

## 结论
- **语义层高相似度段(≥0.55)判得很准**,补上乳腺途径/麦氏点等真实考点=重大价值
- **低相似度段(0.41~0.53)会误合并**(胆道vs甲状腺)
- 正确用法:**仅对相似度中等偏高候选对做语义判重,并设下限阈值**,或 LLM 判后人工兜底

## 推荐方案(供拍板)
- 主流程建议:算法粗筛(0.85,保守)+ 语义层只处理 0.55~0.85 候选对
- 低相似度段不用语义合并,避免误并
